SigNozWatch

Every server's health, in the menu bar.

A tiny menu bar app for SigNoz and Grafana. Error rate, latency, CPU, memory and disk for each machine, grouped by role, with an alert that stays on screen when one turns red.

Install with one command Recommended

curl -fsSL https://github.com/rishavkr08/SigNozWatch/releases/latest/download/install.sh | sh

Open Terminal: press ⌘ Space, type Terminal and press Return. Paste the command and press Return. It installs SigNozWatch to Applications and opens it, with no security warning. Run it again any time to update. Then open Settings… in the panel and paste your SigNoz API key.

What it does

One row per machine

Services from SigNoz traces and hosts from Grafana's Prometheus merge into one row each: requests, error rate, p99, CPU, memory, root disk and load, with three rings underneath.

Grouped by role

Tabs for app servers, web and UI, data stores, tooling and staging, each counting its unhealthy machines. The menu bar dot shows the worst of them all.

Red, orange, green

Orange within 80% of a limit or when a warning rule fires, red over a limit, on a critical rule, or when a machine stops reporting. Limits are yours to set in the panel.

Alerts that wait for you

A notification when a machine turns red or a SigNoz rule starts firing, once per cooldown. Click it to open that machine in SigNoz or Grafana.

Installing the downloaded app

  1. Open SigNozWatch.dmg and drag SigNozWatch into the Applications folder.
  2. Open SigNozWatch from Applications. A dot appears in the menu bar.
  3. When macOS asks whether SigNozWatch may send notifications, click Allow. In System Settings › Notifications, set its style to Alerts so they stay until you close them.
  4. Click the dot, open Settings… and paste your SigNoz URL and API key (SigNoz › Settings › API Keys, Viewer role). Optionally add your Grafana URL with a service-account token or your own user:password.
  5. Tick Launch at login in the panel's footer.
If macOS says “SigNozWatch” can’t be opened because Apple cannot check it, click OK, then:
  • macOS 14 Sonoma: in Applications, Control-click SigNozWatch, choose Open, then click Open in the dialog.
  • macOS 15 or later: open System Settings › Privacy & Security, scroll to the message about SigNozWatch, and click Open Anyway.

You only do this once. The warning appears because SigNozWatch is not notarized by Apple yet. The one-command install above avoids it.
